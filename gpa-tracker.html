GPA Tracker

no app tracked grades the way a college student needed. so i built it.

✦ Problem

Most GPA trackers are either overly simplistic or not considerent for students need. At the same time, platforms like Canvas often don't give a full picture of a student's grade.

This leaves students unsure of their actual standing in a course until the final grade is released.

✦ Design

GPA Tracker was designed as a semester-based grading system that models real syllabus logic rather than simplified GPA calculators.

The system allows users to define courses, grading categories, weights, and assigment structures, enabling dynamic GPA calculation based on real course rules.

This also includes an AI-powered syllabus parses that extracts grading structures from uploaded PDF or Word documents and converts them into structured grading rules.

✦ Implementation

This app was built in Android Studio using Java.

Users can add courses, define grading categories (e.g., exams, homework), and assign weights to each category. The system dynamically calculates GPA and updates progress as grades are modified.

Additional features include reminders, a calendar system, GPA trend visualization, grade distribution analytics, theme customization, and a progression system with experience-based achievements.

✦ What I learned

This was the first app I've ever made, dedicated for a computer science class. It forced me to think outside coding, specially when it comes to UI/UX design, user flow, and what actually will be useful for my target audicence. This project had a timeline set meaning most of the features can be even more optimized and be better integrated in the future.
