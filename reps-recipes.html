Reps & Recipes

UIUC students needed help eating well and staying active without using different platforms. This is why we created R&R.

✦ Problem

Students struggle to maintain fitness goals due to the lack of nutritional info in dining halls, and the friction of using multiple disconnected apps to track their workouts, meals, and progress.

✦ Design

We designed R&R as a unified fitness system for UIUC students that combines computer vision workout tracking, dining hall nutrition data, and progress monitoring into one platform.

The system is split into two main pipelines. A computer vision pipeline for real time exercise tracking, and a data pipeline for scraping and processing dining hall nutritional information.

Each module was built independently and later integrated into a shared backend and fronted system.

✦ Implementation

I was part of the CV subteam where I implemented a real time push up counter using webcam input. The system uses MediaPipe pose estimation to track body joints and detect repetitions based on movement patterns.

The CV pipeline was developed in Python (OpenCV, MediaPipe, Numpy), while the nutrition data pipeline scraped and structured UIUC dining hall menus using HTML parsing.

Later on we integrated these component into an Android Studio application alongside a Kotlin fronted.

✦ What I learned

Since the computer vision pipeline, scraping system, and frontend were built in different environments, we had to spend significant time aligning data formats and restructuring parts of the system to ensure our code worked.

We believe there's space for improvement. We could implement a real time dinning hall experience. More exercises in addition to push ups, and adding personalized recommendations based on combined workout and nutrition data.
