Microcontroller Water Monitor

My fridge was leaking water, so I built a sensor system to catch it before I had a flood in my dorm.

✦ Problem

During my first days in University Housing my fridge broke down and started leaking water. This is why, with my little prior knowledge in microcontrollers, I built a low-cost device that detects water level in the drainage tray and alerts me before it spills.

This later on became the basis for a broader research paper on the potential of microcontroller-based technologies in underserved communities

✦ Design

I approached this problem by breaking it down into a simple embedded system where I needed an input to detect the water, a microcontroller to process the signal, and an output to communicate the result.

Before building the final version, I tested different threshold values and adjusted them based on inconsistent sensor readings caused by noise and water conductivity variation.

✦ Implementation

The system was implemented using an Arduino to read analog values from a water level sensor. The sensor outputs a variable signal, which is read through an analog pin and interpreted using threshold-based logic to classify water levels as low, medium, or high.

A 16x2 LCD display shows the current status in real time, while an LED provides a visual alert when levels become critical.

The system continuously updates readings in a loop, allowing for simple real-time monitoring.

✦ What I learned

Real world sensor data is rarely stable and often requires interpretation rather than direct reading. Small variations in environment and conductivity can affect readings, which made the threshold selection and testing an important part of the project.

If I were to extend this porject, I would implement wireless communication using a second microcontroller to send real time notifications to youer own phone. I would also explore powering the system with a battery for portability, although I realized that continuous sensor reading and LCD usage would significantly reduce battery life, making power efficiency a design constrain.
